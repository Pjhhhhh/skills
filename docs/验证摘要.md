## 受控任务样本

原生 Codex 受控样本覆盖维护项目外普通问答、项目内只读审查、代码与文档修改、用户纠正和途中问题后的续接。样本中的动作与文件结果符合对应要求，代码修改通过夹具已有 3 项检查。输入条件与观察对象见[五类过程检查](真实任务检验.md#全局规则的五类实际过程检查)。

工程方法与验证方法的选用有三类受控读取样本：简单文档修订，按规格实施与故障诊断，应用验证维护及性能比较。该结果支持入口与方法选择的可达性，真实任务的总体收益继续按模型对照实验检验。

## 资料关联与交付

2026-11-12 完成[两个派生案例](真实任务检验.md#资料关联与交付案例)的原版与候选对照。候选在本次试次中检出了跨表缺项和部门冲突，保留正常映射，完成请求指定的 Markdown 交接材料与十八项任务导航；必要事实、原输入保留、入口及成稿内容均已核对。原版跨表成稿将已有明确映射再次列为必须确认，候选本次未出现该问题。

两版使用相同案例、宿主规则、模型配置及更正后的判据。每例每版各一次完成试次，结果支持本次观察，尚不足以判断稳定提升幅度。

A01—A03 的三组固定输入均已分别运行原版、首个候选和修正版。修正版分别生成离线确认 HTML、仓库 Markdown 操作说明和会议比较 HTML，必要事实、输入保留与成稿内容通过核对；两份 HTML 已用实际浏览器打开并查看截图。
